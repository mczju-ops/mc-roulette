# mc-roulette（轮盘赌）

基于 [MCZJUGameCore](https://github.com/mczju-ops/MCZJUGameCore) 的 Paper 小游戏插件：6 格弹夹的俄罗斯轮盘，
2～12 人轮流装填、射击、挑衅、闪避与破坏，每轮还会抽取一个随机事件。

玩法文本来自需求文档，工程结构与写法参考了 `mc-wool-wordle-java`（同样的 MGC 子插件骨架、`MGCItem` 物品、
`JsonGameRoom` 房间配置与 `@FieldDescription` 参数编辑器）。

## 环境

| 项 | 版本 |
|---|---|
| 服务端 | Paper `26.2`（`paper-api 26.2.build.62-beta`） |
| 框架 | MCZJUGameCore `1.0.7` |
| Java | 25 |

版本与参考工程保持一致。如果你的服务端使用其它 MGC 版本，请先确认 `DefaultGameWaitStrategy`、
`DoNothingPlayerQuitStrategy` 仍然存在，再调整 `pom.xml`。

## 构建与安装

```bash
mvn clean package
```

产物：`target/mc-roulette-1.0.0.jar`。

1. 把 `MCZJUGameCore.jar` 和 `mc-roulette-1.0.0.jar` 一起放进 `plugins/`。
2. 启动一次服务器，生成房间目录。
3. 用 MGC 的房间编辑器配置参数（具体命令以你的 MGC 版本为准）：

```
/mgcop room edit mc_roulette <房间ID>
```

### 房间参数

| 字段 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `health` | int | 3 | 每名玩家开局的生命值 |
| `teamMode` | boolean | false | false 个人战；true 团队战（奇数序号一队、偶数序号一队） |
| `startLocation` | Location | 空 | 开局传送点，留空则不传送 |
| `exitLocation` | Location | 空 | 结算 5 秒后返回的位置，留空则不返回 |

建议给每张地图开一个房间；同一个游戏 ID 下可以有多个房间，支持并发对局。

## 实现的规则

### 回合顺序

- 每名玩家随机分配序号 1～N，并显示在号码牌与开局播报里。
- 第 M 轮从序号 `(M-1) % N + 1` 开始，按序号递增依次行动，回到起点时本轮结束。
  例：5 人局第 2 轮 `2→3→4→5→1`；3 人局第 9 轮 `3→1→2`。
- 已淘汰的玩家跳过，且不能被选为目标。
- 每次行动前会播报「第 M 轮 · 第 K 回合 · 行动者」，并附带生命与弹夹信息。

### 五种行动

| 行动 | 物品 | 效果 |
|---|---|---|
| 装填 | 黄色羊毛 | 弹夹 +1（满 6 发时无法装填，不消耗回合） |
| 射击 | 红色羊毛 | 选一名其他玩家，命中率 = 弹药数/6；命中扣 1 血；无论命中与否都清空弹夹 |
| 挑衅 | 橙色羊毛 | 选一名其他玩家，对方朝你开一枪；未命中则你弹夹 +1（满则不加） |
| 闪避 | 蓝色羊毛 | 直到你下一个回合开始前，受伤有 50% 概率免伤，与射击命中率乘算 |
| 破坏 | 紫色羊毛 | 50% 使目标弹药 -1；失败时目标可选择是否开枪反击 |

弹夹（箱子）实时显示 `装填弹药数 Y/6`，号码牌（纸）显示序号与当前生命。

### 每轮随机事件

先掷 1/3 概率「无事发生」，剩下 2/3 按权重抽取；走火权重是其它事件的一半，其余平分。

| 事件 | 权重 | 效果 |
|---|---|---|
| 无事发生 | 1/3 | 本轮没有特殊事件 |
| 走火 | 1 | 本轮所有人的行动固定为射击 |
| 非攻 | 2 | 本轮不能射击、挑衅，被破坏后也无法反击 |
| 逆流 | 2 | 本轮行动顺序整体反转：原本最后行动的人先手 |
| 陨星 | 2 | 每名玩家回合结束时 1/3 概率扣 1 血，闪避生效；未命中也会播报 |
| 短视 | 2 | 选择目标时只能选行动顺序中的下一名玩家 |

两人局里短视没有任何可观察的效果（本来也只能选另一名玩家），因此两人局不会抽到短视。
每轮开始都会播报「本轮行动顺序：#2 → #1 → #5 → #4 → #3」，可以直接核对逆流是否生效。

### 胜负

- 个人战：淘汰其他所有人者获胜。
- 团队战：序号奇数一队、偶数一队，淘汰对方全队获胜。
- 玩家中途退出按淘汰处理，其余玩家继续对局；场上无人存活时判平局。

## 交互细节

- 不在自己回合右键行动物品 → 聊天栏提示「现在不是你的回合」。
- 选择目标：右键射击/挑衅/破坏后弹出玩家头颅菜单，点击选择，30 秒未选自动取消（不消耗回合）。
- 破坏失败的反击确认：目标会收到 15 秒的「立刻反击 / 放弃反击」菜单。
- 号码牌或弹夹右键可随时查看自己的序号、生命、弹夹与当前事件。
- 本局物品不能丢弃、不能放置成方块。

## 规则层面的取舍（需求未写明，按下列方式实现）

1. **挑衅与反击也要清空弹夹**：需求写的是「射击一次」，按射击的通用规则处理；挑衅未命中后挑衅者 +1 发。
2. **对空弹夹破坏必失败**：需求以「子弹数没有减少」定义失败，因此目标 0 发时破坏一定失败并触发反击询问。
3. **走火与非攻不会同轮出现**：每轮只抽一个事件，二者互斥；若未来改动为多事件，需要重新定义优先级。
4. **号码牌额外显示生命**：需求只写了序号，这里追加了一行生命值，方便玩家判断局势。
5. **没有回合时限**：需求未要求，行动方不操作时对局会等待；如需防止挂机可后续加超时自动跳过。
6. **死亡策略使用 MGC 默认**：本插件只用自维护的生命值扣血，不调用 Bukkit 伤害，避免真实死亡与掉落。
